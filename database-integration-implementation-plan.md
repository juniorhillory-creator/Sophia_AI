## 2. Database Integration Strategy

### 2.1 Post-Integration Architecture

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        POSTGRESQL (Source of Truth)                         │
│  ┌─────────────┐  ┌──────────────┐  ┌────────────────┐  ┌──────────────┐  │
│  │   users     │  │  documents   │  │ oauth_accounts │  │ reset_tokens │  │
│  │  (auth)     │◄─┤  (metadata,  │  │   (google)     │  │  (password)  │  │
│  │             │  │   status,    │  │              │  │              │  │
│  │             │  │   user_id)   │  │              │  │              │  │
│  └─────────────┘  └──────────────┘  └──────────────┘  └──────────────┘  │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                    ┌───────────────┼───────────────┐
                    ▼               ▼               ▼
            ┌─────────────┐ ┌─────────────┐ ┌─────────────┐
            │  FILESYSTEM │ │  CHROMADB   │ │  IN-MEMORY  │
            │  (PDFs,     │ │  (Vectors,  │ │  (Session   │
            │   chunks,   │ │   metadata) │ │   Cache*)   │
            │   pages,    │ │             │ │             │
            │   summary)  │ │             │ │             │
            └─────────────┘ └─────────────┘ └─────────────┘
```

**Role of each storage layer after integration**:

| Layer                        | Responsibility                                                                  | Survives Restart | User Isolation                                         |
| ---------------------------- | ------------------------------------------------------------------------------- | ---------------- | ------------------------------------------------------ |
| **PostgreSQL**               | User accounts, document metadata, status, ownership, OAuth tokens, reset tokens | ✅ Yes           | ✅ Row-level (user_id FK)                              |
| **Filesystem**               | Original PDF, extracted pages (JSON), chunks (JSON), cached summary (JSON)      | ✅ Yes           | ✅ Per-document directory (`data/documents/{doc_id}/`) |
| **ChromaDB**                 | Embedding vectors + metadata (document_id, page, chunk_id)                      | ✅ Yes           | ✅ Query-time filter by `document_id`                  |
| **In-Memory (SessionStore)** | **Eliminated** — replaced by DB + filesystem reads                              | ❌ No            | N/A                                                    |

**Key principle**: PostgreSQL is the **authoritative index** for "what documents exist and who owns them". Filesystem and ChromaDB are **content stores** keyed by `document_id` (UUID). No data lives only in memory.

### 2.2 Data Flow After Integration

```
Upload (POST /api/v1/documents)
    │
    ▼
Auth: get_current_user → user_id
    │
    ▼
Validate PDF (size, mime, magic bytes)
    │
    ▼
Create DB Document row: status="processing", stage="extracting", user_id
    │
    ▼
Save PDF to filesystem: data/documents/{doc_id}/original.pdf
    │
    ▼
Background Task (or sync for MVP):
    ├── Extract pages → save pages.json
    ├── Chunk pages → save chunks.json
    ├── Embed chunks → ChromaDB upsert (metadata: document_id, user_id)
    ├── Update DB: stage="indexing" → "summarizing" → "ready"
    └── Generate summary → save summary.json + update DB
    │
    ▼
Response: 202 Accepted {id, filename, status, stage} (async)
        OR 201 Created {id, filename, page_count, chunk_count, status: "ready"} (sync MVP)
```

**New dependency signature**:

```python
# app/dependencies.py
async def get_current_user(
    request: Request,
    db: AsyncSession = Depends(get_db),
) -> UUID:
    auth = request.headers.get("Authorization")
    if not auth or not auth.startswith("Bearer "):
        raise AppError("unauthorized", "Missing or invalid Authorization header", 401)
    token = auth[7:]
    try:
        payload = jwt.decode(token, settings.jwt_public_key_path, algorithms=[settings.jwt_algorithm])
        if payload.get("type") != "access":
            raise AppError("invalid_token", "Invalid token type", 401)
        return UUID(payload["sub"])
    except jwt.ExpiredSignatureError:
        raise AppError("token_expired", "Access token has expired", 401)
    except jwt.JWTError:
        raise AppError("invalid_token", "Invalid access token", 401)
```

**Dependencies**: Phase 0 (Database initialized)

**Tests**:

- Unit: `get_current_user` rejects missing/invalid/expired tokens
- Integration: `POST /auth/login` → use token to access protected endpoint

**Risks**:

- Public key file not found → ensure `keys/public.pem` exists (already generated)
- Clock skew → tokens use UTC, ensure server time sync

**Status State Machine** (persisted to DB at each transition):

```
UPLOAD (202)
  │
  ▼
status="processing", stage="extracting"     ← PDF saved, pages not yet extracted
  │
  ▼ (extract_pages succeeds)
status="processing", stage="indexing"       ← Pages extracted, chunks created, embedding
  │
  ▼ (chunks embedded + upserted to ChromaDB)
status="processing", stage="summarizing"    ← Chunks indexed, summary generation
  │
  ├─► SUCCESS: status="ready", stage=null   ← Document fully processed
  │
  └─► FAILURE: status="failed", stage=<failed_stage>, error_code, error_message
```

**Failure Handling**:

- Each stage wrapped in try/except
- On exception: update DB row to `status="failed"`, `stage=<current_stage>`, `error_code`, `error_message`
- Do NOT leave document in `processing` without a stage
- Startup recovery: any `status="processing"` → `status="failed"`, `error_code="interrupted"`, `error_message="Processing interrupted by restart"`

**Startup Recovery** (in `app/main.py` `create_app` or lifespan):

```python
async def startup_recovery():
    async with get_database().session() as session:
        stuck = await session.execute(
            select(Document).where(Document.status == DocumentStatus.processing)
        )
        for doc in stuck.scalars():
            doc.status = DocumentStatus.failed
            doc.error_code = "interrupted"
            doc.error_message = "Processing interrupted by restart"
            doc.updated_at = datetime.now(timezone.utc)
        await session.commit()
```

| Endpoint                         | Auth Required         | Ownership Check                                | Failure Response       |

| `GET /documents/{id}`            | ✅ `get_current_user` | Verify `doc.user_id == current_user`           | 404 if not owned       |
| `GET /documents/{id}/chunks`     | ✅ `get_current_user` | Verify `doc.user_id == current_user`           | 404 if not owned       |
| `POST /documents/{id}/summary`   | ✅ `get_current_user` | Verify `doc.user_id == current_user`           | 404 if not owned       |
| `GET /documents/{id}/summary`    | ✅ `get_current_user` | Verify `doc.user_id == current_user`           | 404 if not owned       |
| `POST /documents/{id}/questions` | ✅ `get_current_user` | Verify `doc.user_id == current_user`           | 404 if not owned       |
| `GET /documents/{id}/file`       | ✅ `get_current_user` | Verify `doc.user_id == current_user`           | 404 if not owned       |
| `DELETE /documents/{id}`         | ✅ `get_current_user` | Verify `doc.user_id == current_user`           | 404 if not owned       |

**JWT Validation Checklist** (in `get_current_user`):

- [ ] Authorization header present and starts with "Bearer "
- [ ] Token signature verified with RS256 public key
- [ ] Token not expired (`exp` claim)
- [ ] Token type is "access" (not "refresh")
- [ ] Subject (`sub`) is valid UUID
- [ ] User exists in database
- [ ] User `is_active = true`

### 6.2 Risk Matrix

| Risk                                      | Likelihood | Impact | Mitigation                                              |
| ----------------------------------------- | ---------- | ------ | ------------------------------------------------------- |
